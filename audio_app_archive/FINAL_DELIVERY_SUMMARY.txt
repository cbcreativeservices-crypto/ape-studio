POST-REVIEW PROCESS
================================================================================

COLLECT (Week 1-2)
  □ Ask instructors to send JSON files
  □ Set deadline (e.g., 2 weeks after distribution)
  □ Offer deadline extension if needed

CONSOLIDATE (Week 3)
  □ Gather all JSON files
  □ Copy content to spreadsheet or text document
  □ Group flagged terms together
  □ Sort by frequency (most flagged first)

ANALYZE (Week 3)
  □ Look for patterns:
     - Same term flagged by multiple instructors? (Priority fix)
     - Similar issues across different terms? (Systemic problem)
     - Individual vs. consensus feedback? (Weight accordingly)
  □ Note quick fixes vs. major rewrites
  □ Identify terms that are fine (no flags)

UPDATE (Week 4)
  □ Edit Master Excel file based on feedback
  □ Re-generate tool with updated definitions (if needed)
  □ Test updated tool with 5-10 terms

SHARE RESULTS (Week 4)
  □ Thank instructors for feedback
  □ Share summary of changes made
  □ Distribute updated glossary
  □ Save feedback files for records

================================================================================
COMMON QUESTIONS
================================================================================

Q: Can instructors see each other's flags/comments?
A: No. Each instructor's data is stored only on their device.

Q: Will comments be lost if browser cache is cleared?
A: Yes. Recommend instructors export before clearing cache.

Q: Can instructors work on multiple devices?
A: Each device has separate storage. They'd need to export and share.

Q: How do I update the glossary for next semester?
A: Update Excel file, regenerate HTML tool with new definitions.

Q: What if an instructor has technical problems?
A: See Troubleshooting section in Quick Start Guide.
   Most issues solved by: hard refresh, different browser, or re-opening file.

Q: Can I customize the tool for my needs?
A: Yes. HTML file is well-commented and can be modified by a developer.

Q: Is the data stored on a server?
A: No. All data is stored locally on instructor's device. Completely private.

Q: How long does review take?
A: ~1 hour for thorough review (239 terms). Can be done in multiple sittings.
