EXPORT DIALOG
=============

When instructor clicks "📥 Export Flagged":

1. Browser downloads: MUSI190_FlaggedTerms_2026-05-14.json

2. Alert appears: "✓ Exported 5 flagged term(s)!"

3. File can be opened with:
   - Text editor (Notepad, VS Code, etc.)
   - Excel (to view as table)
   - Sent to course coordinator
   - Attached to email

================

When instructor clicks "🗑️ Clear All Flags":

┌─────────────────────────────────────────┐

│                                          │
│           [Cancel]  [Yes, Clear All]    │

- Cancel: Returns to glossary, nothing changes
- Yes, Clear All: Removes all flags and comments

KEYBOARD NAVIGATION EXAMPLE
===========================

User presses TAB repeatedly:

1. Tab → Focus on Search Box
2. Tab → Focus on Export Button
3. Tab → Focus on Clear All Button
4. Tab → Focus on First Checkbox
5. Tab → Focus on Comment Box (if flagged)
6. Tab → Focus on Clear Comment Button (if flagged)
7. Tab → Loop back to next term or search box

User can also:
- Press SPACE to toggle checkbox
- Press ENTER to click buttons
- Type in comment box

        Easier to scan quickly
        Less scrolling needed
