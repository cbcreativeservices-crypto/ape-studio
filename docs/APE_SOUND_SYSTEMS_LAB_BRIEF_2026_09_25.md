# Sound Systems Lab — owner brief (2026-09-25)

Status: BRIEF RECEIVED. NOT a go. Nothing designed or built.
Owner's term: use "live sound reinforcement" throughout.
Goal: start with an empty venue, finish having designed, wired, routed, tested,
tuned and troubleshot a complete live sound system.

## Chapters (owner's list, condensed — scope is the full list the owner gave)
1. Understanding the complete PA system — every section source→listener; tap any component to see where its signal comes from and goes next.
2. PA system types — powered small PA, passive+amps, column array, club, church/multipurpose, corporate, outdoor, large line array, distributed, front/side/under-balcony fills and delays. Explain WHEN each is appropriate.
3. Output configurations (a KEY section) — mono, dual mono, stereo, LCR, 2.1, mono mains + separate sub out, stereo mains + mono subs, stereo subs, no subs, multiple zones, mains+front fills, mains+delays, lobby/recording/broadcast/overflow feeds. Users HEAR and SEE what changes.
4. Mixer routing and bussing — inputs, main bus, auxes, pre/post sends, subgroups, VCA/DCA, mute groups, matrices, direct outs, control-room/monitor outs, solo/PFL/AFL, inserts, digital + output patching, one signal to many destinations. KEY GOAL: when to use a subgroup vs aux vs matrix vs DCA.
5. Subwoofer deployment and routing — range, powered/passive, crossover basics, HPF/LPF, processor vs internal crossover, main-through-sub, dedicated output, aux-fed, matrix-fed, which channels feed subs, level, polarity/phase, crossover alignment, ground-stacked/flown, center cluster, L-R, cardioid and end-fire, LF buildup. COMPARE crossover-fed vs aux/matrix-fed.
6. Stage monitors and performer mixes — wedges, side fills, drum fills, IEMs wired/wireless, pre-fader mixes, post-fader FX sends, multiple mixes, monitor vs FOH console, analog split vs digital gain sharing, talkback, monitor feedback, safe IEM levels, stereo vs mono IEM.
7. Wiring and system connections — link to the Connectors lab rather than duplicate. Balanced/unbalanced, mic/line/instrument/speaker level, XLR/TRS/TS/speakON/Ethernet/digital, powered and passive hookups, no speaker level into line inputs, snakes/stageboxes, AES3/Dante/AVB/MADI, clocking and sample rate, routing and strain relief, signal vs power cables, ground loops/isolation, redundancy, labelling/documentation.
8. Amplifiers and loudspeaker compatibility — power ratings, continuous/program/peak, nominal impedance, parallel loads, minimum safe impedance, bridging, limiting, clipping, headroom, sensitivity and max SPL, powered-speaker gain, HF driver protection, amp selection, unsafe combinations. INTERACTIVE CALCULATIONS + WARNINGS on unsafe loads.
9. System setup and deployment — the owner's 16-step professional sequence (assess → coverage/SPL → select → place/aim → power distribution → position FOH/stage → run cables → patch → verify routing before powering speakers → power-up order → test every I/O → gain structure → tune/align → soundcheck → document → shutdown order).
10. Gain structure and signal levels — interactive signal-chain meter source→loudspeaker; preamp, meters, faders, bus/subgroup, main/matrix, processor I/O, amp sensitivity, powered-speaker input, noise floor, SNR, headroom, analog vs digital clipping, unity, gain-before-feedback, power-up/down order.
11. Speaker placement, coverage and alignment — coverage angle, H/V dispersion, height/aim, near/far field, overlap, comb filtering, interference, front fills, delay speakers, delay-time calcs, acoustic vs electronic delay, polarity, time alignment, sub alignment, mic placement vs speakers, indoor vs outdoor. Venue-view simulation (coverage, overlap, level, timing).
12. Processing and system tuning — input vs system EQ, HPF, crossovers, PEQ, GEQ, delay, polarity, phase, limiters, presets, measurement mics, RTA and transfer function, reference positions, consistency not one perfect seat, verify by listening, save/recall. Link to existing tuning/RTA/SPL/spectrum tools.
13. Feedback control — the loop, GBF, placement, polar patterns, stage volume, monitor feedback, finding frequencies, narrow EQ carefully, why heavy GEQ hurts, automatic suppressors, muting unused mics, what to do mid-show.
14. Testing and troubleshooting — 22 fault exercises (no sound anywhere; one input dead; left speaker dead; no subs; reaches mixer not speaker; speaker distortion; amp clips; hum/buzz; ground loop; bad digital patch; wrong bus; pre/post error; reversed polarity; wrong crossover; limiter over-active; clocking; network dropout; delay early/late; monitor moves with main fader; vocals in subs; soundcheck feedback; intermittent cable). Troubleshoot FROM THE SOURCE FORWARD, never random swapping.

## Five modes
Learn (guided, animated flow) · Build (drag components into a venue and connect) · Route (console buses/outputs/groups/matrices) · Operate (soundcheck, gain, run the show) · Troubleshoot (diagnose inserted faults).

## Ten capstones (progressive)
Speech 1 mic + 2 powered · small mono music · stereo band + subs · 2.1 with dedicated sub out · band with 4 monitor mixes · subgroups + FX · matrices for mains/fills/lobby · outdoor with front fills + delays · digital stagebox + networked audio · festival: mains, subs, monitors, recording, broadcast.

Principle: complete-system thinking here; existing connector, tuning, measurement, safety and cable labs give depth.
