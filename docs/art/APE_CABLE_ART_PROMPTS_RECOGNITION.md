# Cable Lab Artwork Prompts — RECOGNITION TIER (T3)

**Master spec:** `docs/art/APE_CABLE_ART_SPEC_2026_08_16.md` — all global rules apply
(transparent background, key light upper-left + rim lower-right, no logos/brands,
NO text or numbers baked into the image, PNG, side/three-quarter canvas 1600×1000,
face canvas 1000×1000, max ~2 MB).

**Verified source of facts:** `src/screens/lab/cable/data/connectors.recognition.ts`
(B2 fact-verification protocol). Every hard constraint below comes from that file
or from well-known standard geometry; everything finer defers to real product
references.

**View set for this tier:** ONE identification-quality side / three-quarter view
per connector (`<id>__side.png`). Three exceptions add a face view because the
pin count IS the identification: `db25`, `xlr4`, `xlr5` each get a
`<id>__face-plug.png`. No receptacle-face, mating, or T5 exploded views at this
tier (T5 is core-connectors-only per master spec §1).

**Qualified-person four** (`nema_twist_lock`, `stage_pin`, `cam_type`,
`socapex_style`): render pristine, professional, and strictly neutral — static
identification subjects. No hands, nothing mated or plugged in, nothing that
invites interaction. These are mains-power connectors taught as
recognition-and-keep-clear only.

**Prompt count: 18** (15 side views + 3 face views).

## Integration notes (not prompts)

- **No reuse mappings in this family** — all 15 connectors get their own art.
- **Differentiation pairs to eyeball at delivery:** `tt_bantam` vs
  `quarter_patch` (diameter + tip profile), `lk_veam` vs `socapex_style`
  (dark quarter-turn signal shell with many fine contacts vs satin threaded
  power shell with 19 heavy contacts), `mini_xlr` vs the core `xlr3` side view
  (overall size and cable weight).
- **Face-geometry verification pass** applies to the three face views
  (`db25__face-plug`, `xlr4__face-plug`, `xlr5__face-plug`) before any pin
  overlays are enabled, per master spec §3.2 — although recognition-tier
  lessons never assess pins, so overlays may simply stay off for this tier.
