**23 images**, produced in two stages. These are the "List B" (genuinely new)
gaps from the lab image survey — components the labs currently draw in code or
describe in text, with **no existing photo** in the `glossary-images` bucket.

- **Stage 1 — Tier 1 (12):** highest learner value — mics, loudspeakers,
  acoustic treatment, instruments. Run this batch first.
- **Stage 2 — Tier 2 (11):** outboard studio gear (Gain/EQ/Digital/FX labs).
- **Tier 3** (calibrators, balloon, power amp, strobe) is deliberately **NOT**
  in this package — shelved to post-launch by owner ruling.

  separate wiring task, not image production — held for the owner's go.

## House style — identical to your approved term/connector images

Every prompt below already contains this; repeated here as the reference:

> Photorealistic product photograph, seamless pure-white background, soft even
> studio lighting with a subtle contact shadow beneath the object, three-quarter
> view angled diagonally across a square frame, object filling ~85% of frame,
> crisp focus, realistic materials, **no text, no logos, no branding**, generic
> unbranded product, 1240×1240.

**Delivery:** WebP, filenames exactly as given (kebab-case, matching the bucket
convention), uploaded to the same public `glossary-images` bucket. Send me the
list when they're up and I map them into the lab cards.

**Accuracy note:** the "must show" line on each item lists the features that make
the object identifiable and correct for what the lab teaches. An image that gets
one wrong teaches the wrong thing; everything else can follow real product
references.

**Owner creative calls** (a prompt default is set for each; change if you like):
line array = J-shaped flown column · crossover = passive component network (not
an active rack unit) · absorber = fabric-wrapped rigid panel · console = compact
analog mixing desk (not a single channel strip) · delay/modulation/distortion =
studio rack/pedal idiom noted per item.
