# Head fix — 2026-10-08 (owner-approved)

**Owner rule:** "The head icons are only to be used when a head is alone. They are not to be used when attached to a body."

- A head on its own (a listener, a talker, a marker on a plan) uses the owner's line-art icon.
  - **SIDE** (profile) for side-on scenes.
  - **ABOVE** for plans seen from above. The icon is turned to the way the person faces (owner decision 1).
- A head on a body uses the figure's own skin-silhouette head: the Miking `PlayerFigure` / `FigureHead` look from 6 October (owner decision 2). It is never the icon and never a circle.
- A crowd may be drawn as seats without people. It is never drawn as circle "heads" (owner decision 3).

Before/after pictures at phone width (390 pt) are in `docs/art/head_fix_2026_10_08/`. Each picture is one pair, before on the left and after on the right.

## The shared modules (new)

| File | What it is |
|---|---|
| `src/features/lab/headIconGeometry.ts` | The two icons as plain geometry. No Skia and no SVG inside. **SIDE** is the micspeaker profile canon, moved here unchanged (authored facing left, origin at the mouth). **ABOVE** is traced from `assets/Head_icon_above.PNG`: stroke centre-lines measured from the art, crown→chin = 100, the chin end facing down the screen. `aboveRotation(dx, dy)` turns it to face any direction. `appendHeadIcon()` adds an icon at a given position into one shared path, so a whole crowd costs one path. It also holds the SVG path strings. |
| `src/features/lab/headIcons.tsx` | The Skia renderer: `HeadIcon` (view, size or scale, facing, rotation, anchor origin/center/neck, tint, plate, glow, speaking) and `makeHeadIconPaths` / `HeadIconPaths` for crowds. |
| `src/features/lab/headIconsSvg.tsx` | The react-native-svg renderer: `HeadIconSvg` (same props) and `HeadGlyph`, an icon in its own hidden-or-labelled `<Svg>`. |
| `src/features/lab/figureHead.tsx` | `FigureHeadAt`: PlayerFigure's `headFront` / `headProfile` / `headAbove` plus `FigureHead`, scaled into a pixel- or metre-based scene. The contour never gets thinner than a readable minimum. |
| `src/features/lab/figureHeadSvg.tsx` | `FigureHeadSvg`: the same skin-silhouette head for SVG screens. It uses the skin gradient, a lit crescent and a core-shadow crescent cut with even-odd fills inside a clip, and a contour. |

`micspeaker/viz.tsx` now draws its `ProfileHead` through the shared `HeadIcon`. The paths and the transform order are the same as before, so its five profile heads do not change (`distance.jpg`). The unused `buildFrontHead` / `FrontHead` copy and the bust helpers have been removed.

- Everything else the grep turned up named "head" is not a person: drum heads, mallet heads, beaters, stick tips, a cymbal-holder knob, the bass amp "head", an animal in `field/SiteArt`, and a chart point in `hubPreviewsSim`.
- f10 Spatial Field: the listener mark is a ring for a measuring point, not a head. Its people are already shared figures.
- `wave/vizWave` RoomSceneView keeps the owner's own PNG (`head-front.png`), only turned. Its small on-screen size (a 14 px floor) is unchanged.
