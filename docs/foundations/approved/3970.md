Topic Foundations: DAW Fundamentals and Session Management

Imagine a band recording a song at home. One computer program can record, edit, mix, and finish it. Because it works like a full studio on a screen, it is called a digital audio workstation. It needs a lot of the computer's power. A part of the program that you do not see does the actual recording and playback. Small helper programs connect it to the device that the microphones plug into.

Everything the band records is saved as sound files on a drive. The program keeps one project file, called a session. The session remembers how the song is built, but it does not contain the sound. It points to files in a folder beside it. So the session and its folder must always be copied together. Otherwise, the song opens with missing sound.

Inside the session, time is shown from left to right. Each instrument is placed in its own row, called a track. Some tracks hold recorded sound, some hold played notes, and some combine several tracks into one signal path. Clear names, colors, and labeled points on the timeline make it easy to find things in a large session. Many people start from a saved, ready-made session, so every song begins organized.

With the tracks ready, you fill them. You switch on the tracks that should record and press record. To fix one sung line, you can start recording at an exact point and stop again right after. Usually each new attempt becomes a new file, so earlier attempts stay safe.

Those saved attempts make editing safe too. The program rarely changes the files themselves. It keeps notes about which pieces play and where. Settings decide whether pieces remove the gaps between them, move freely, or snap to the beat lines. You can even build one best performance from the best parts of several attempts.

Snapping to beat lines only works if the program knows the song's speed. A plan of the tempo, even a changing one, gives it that grid. Then late notes can be moved onto the beat, and recordings stretched without changing pitch.

Last, it remembers your mixing changes, can turn tracks that use a lot of computer power into fixed audio to reduce the load on the computer, and writes the mix, or some tracks, into a new file, a step called a bounce. By the end of this topic, you will know how the program and computer work together, and how a session is set up, recorded, edited, timed, finished, and saved so it still opens correctly months later.
