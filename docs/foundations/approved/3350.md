Topic Foundations: Compression, Limiting and Gating

Imagine a friend singing while you record. Some words are sung very softly, and then the chorus is loud. You could keep your hand on the volume knob for the whole song, turning it down for loud parts and up for soft parts. So how can a tool do that job automatically, and how does it decide when to act?

A machine cannot guess what "too loud" means, so you give it a set level. That level is called the threshold. A tool that turns down sound above the threshold is called a compressor. Its ratio sets how much it turns that sound down. You also set how fast it starts and stops, or let it set them automatically. A fast start can reduce the sharp beginning of a drum hit, and a slow start lets it through. Because the loud parts are now lower, the whole sound is quieter, so you raise its level again.

If you set the ratio very high, loud moments stay at the threshold instead of going above it. A compressor set this way is called a limiter. Simply cutting off the peaks instead can add more distortion.

The same idea can work in reverse. In the pauses, the microphone still picks up a fan or a hiss. A tool can turn down sound below its own threshold, often almost to silence, and turn it up again when the voice returns. That tool is called a gate. A related tool, the expander, turns quiet sounds down more gradually, by a ratio that you set.

Each tool depends on how it measures the sound. Some measure short peaks, and others the average level. The path that carries the sound to this measuring part is called the sidechain. It can be filtered, so a bass note does not trigger the tool, or so the tool reacts only to the hiss of an "s". It can even measure a different sound, so music gets quieter whenever a voice speaks.

Some compressors act on only part of the sound. They divide it into frequency bands, each with its own compressor, so a loud bass note does not lower the cymbals. The circuit design matters too. Circuits that use light, a transistor, a chip or vacuum tubes each react at a typical speed. Some also add a small amount of distortion.

All these tools change how each sound rises and falls. Related tools raise or lower the start of each sound and the part after it, separately. When these changes are too large, the level can rise and fall in a way you can hear, or a gate can open and close too often.

The flashcards explain each control, tool and design in detail. By the end, you will know how these tools decide when and how much to act, and how they can improve or damage the sound.
