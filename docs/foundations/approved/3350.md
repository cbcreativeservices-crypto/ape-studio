Topic Foundations: Compression, Limiting and Gating

Imagine a friend singing while you record. Some words are sung very softly, and then the chorus is loud. You could keep your hand on the volume knob for the whole song, turning it down for loud parts and up for soft parts. Every tool in this topic does that job automatically.

But a machine cannot guess what "too loud" means, so you give it a set level. That level is called the threshold. A tool that turns down sound above the threshold is called a compressor. You set how much it turns the sound down, and how fast it starts and stops. A fast start can reduce the level of the sharp beginning of a drum hit. A slow start lets it through. Then you raise the level of the whole sound again.

If you set the amount to the maximum, loud moments stay at the threshold instead of going above it. A compressor set this way is called a limiter. It sets a maximum level. Simply cutting off the peaks instead can add more distortion.

The same idea can also work in the opposite direction. In the pauses, the microphone still picks up a fan or a hiss. A tool can turn down sound that is below its own threshold, often almost to silence, and then turn it up again when the voice returns. That tool is called a gate. A related tool, the expander, only turns quiet sounds down a little.

Each of these tools depends on how it measures the sound. Some measure the short, sharp peaks. Others measure the average level. The path that carries the sound to this measuring part is called the sidechain. It can be filtered, so a bass note does not trigger the tool, or so the tool reacts only to the hiss of an "s". It can even measure a different sound, so music gets quieter whenever a voice speaks.

The design of the tool also matters. Designs built with a small light, a fast transistor, a chip, or vacuum tubes each have their own typical speed and tone. Because they all change how sounds rise and fall, they can make drum hits louder or quieter compared with the rest of the sound. When the settings are too extreme, the music rises and falls in an unnatural way, or a gate opens and closes too often.

The flashcards build on this idea. They cover the threshold and timing controls, the ways these tools measure sound, limiters and gates, the different designs, tools that set their own timing, tools that change the start of each sound, and tools that work on one range of frequencies. By the end, you will know how these tools decide when and how much to act, and how they can improve or damage the sound.
