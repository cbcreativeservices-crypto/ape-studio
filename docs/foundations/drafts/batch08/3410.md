Topic Foundations: Plugin Formats, Hosts and Processing

Imagine you install a new reverb from one company, and it appears inside another company's recording program. A small add-on program like this is called a plugin. The program that loads it is called the plugin host. How can one company's add-on run inside another company's program, and at the correct time?

The answer starts with shared rules. A plugin is built to an agreed standard, so any host that follows that standard can load it. That standard is called a plugin format. Different companies created formats for different computer systems, and a host opens only the formats it supports. Some old formats are no longer used. A wrapper or bridge can let a host load a plugin it cannot open alone.

When the host finds a new plugin, it tests it before it adds it to its list of plugins. Some hosts run each plugin in a separate, protected space, so if one plugin fails, the whole program keeps running. The host must also keep every plugin in time. Some plugins must receive a short part of the sound before they can process it, so their output comes late. That delay is called plugin latency. The host delays every other track by the same amount, so all the tracks stay together. This is called plugin delay compensation.

Every plugin also uses computer power. Most run on the computer's main processor, and when the plugins need too much power, the sound can stop or click. Some systems add extra processing chips in a separate box or card. Another solution is to turn a finished track and its effects into a plain audio file.

A plugin also needs permission to run. The maker checks for a license, which may be stored on the computer, on a small device that plugs into it, or in an online account. Some licenses are paid once, and others work only while you pay a regular fee.

Once a plugin runs, what does it do? Many plugins copy real studio equipment: mixing consoles, compressors, tape machines and reverb units. Engineers measure how the original circuit changes the sound, and the software calculates the same change. This is called analog modeling. The same idea copies guitar amplifiers, speaker cabinets, effect pedals and microphones. Other plugins are instruments that create sound instead of changing it. Another group of plugins repairs recordings: it removes noise and room echo, corrects pitch, or splits a finished song into separate parts. Some tools measure a track and suggest starting settings.

The flashcards explain the formats, how hosts load and time plugins, processing power, licenses, and the main groups of processors. They also name the products you will see in studios. By the end, you will know how a plugin is loaded, kept in time and paid for, and what kind of processor each product name describes.
