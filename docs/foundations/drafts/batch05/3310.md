Topic Foundations: Recorders & File Formats

Imagine you record an interview with a friend on your phone. Later, the file plays on someone else's device too. Three things made that possible. A machine captured the sound, something stored it, and the file followed agreed rules. This topic answers one question: how is sound captured, stored and saved so that it can be played later?

Start with the machine. Besides phones, small portable recorders use batteries and are carried to film sets and interviews. Some start only when a sound is detected. Studio recorders record many microphones at once, each on its own track, so each part can be changed later. That method is called multitrack.

Every recorder has similar controls. You choose the input, set the recording level, and listen through headphones. To fix one bad moment, you can record over only that part. Many recorders also keep the last few seconds of sound in memory all the time, so the start of a sudden sound is not lost. That memory is called a pre-record buffer. On a film set, the engineer speaks the number of each attempt, or take, into a small built-in microphone. It is called a slate mic, short for slate microphone. A clock shared with the cameras marks each moment, so sound and picture can be matched later.

These recordings must be stored somewhere. Most modern recorders save to memory cards or drives with no moving parts. The card must save data fast enough, without pauses, or part of a recording can be lost. Careful crews often record a second copy at the same time.

Before memory cards, sound was stored on physical media. Many early machines cut a wavy groove into a disc, and a needle followed it during playback. Later, magnetic tape stored sound on reels and in cassettes. The speed of the disc or tape often changed how long it played and its sound quality. Then digital media stored sound as numbers, on tape or on discs read by a laser.

Today, digital sound is saved as a file. The agreed layout for how information is stored in a file is called the file format. Professional formats often keep the sound exactly as recorded, with extra information stored inside, such as the scene and take. A tool that makes the sound file smaller for storage and restores it for playback is called a codec. Some codecs give back the exact original. Others remove sounds that people are least likely to hear. That method is called lossy encoding, and the removed detail cannot be recovered.

The flashcards cover the recorders, their controls and time marks, today's storage, older tape and disc media, and file formats and codecs. By the end, you will know how a recorder captures sound, where it is stored, and how it is saved for playback.
