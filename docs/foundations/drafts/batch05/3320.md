Topic Foundations: Dante and Networked-Audio Routing

Imagine a large concert. Every microphone on stage needs its own wire to the mixing console at the back. All those wires are bundled into one heavy cable. Today, many shows replace it with one thin network cable. So how can one thin cable carry hundreds of sounds, and how do you decide where each sound goes?

The answer starts with how computers share information. A network connects many devices, so each one can send data to any other. The data travels in many small packages, sent one after another. Every device follows the same agreed rules for sending them. Such a set of rules is called a protocol. There are many kinds of networks, wired and wireless, but most audio networks use the common wired type found in offices.

Networked audio puts sound into those packages. A stage device changes each microphone signal into numbers and sends them across the network. The most widely used system for this is called Dante. It is built into consoles, stage boxes, amplifiers and recording interfaces. Software can also turn an ordinary computer into a Dante device. One cable carries the sound and the control messages together.

The packages must arrive in time, or the sound stops. To save capacity, a sender groups several channels and sends them together. That group is called a flow. Each device can handle only a limited number of flows, and more channels use more of the cable's capacity. Packages also arrive at uneven times, so the receiver holds them for a very short moment before playing them. A longer wait is safer but adds delay. On a busy network, timing and audio packages can be sent before other data. This is called quality of service.

Next, every device must find the others. Each device announces its name automatically, and the control software lists them all. Each device has sending channels and receiving channels. On a grid in the software, you choose which sending channel each receiving channel plays. That connection is called a subscription. No cable moves, and one sending channel can be played by many receivers.

Not every device uses Dante. Other systems send many channels over network cable, other kinds of cable, or glass fiber. Shared public standards let different systems exchange audio on one network. When many systems and people share a network, it needs protection. Devices can be sorted into named groups with their own logins and permissions. Such a group is called a domain.

If sound stops arriving, technicians usually check the small light beside the cable socket, the cable, the device names and then the subscriptions. The flashcards explain each part in detail: the network underneath, the devices, flows and timing, connecting channels, other systems, and protection and repair. By the end, you will know how many sounds share one cable, and how each sound reaches the right place.
