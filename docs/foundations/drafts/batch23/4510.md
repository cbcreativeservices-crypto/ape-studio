Topic Foundations: Immersive Audio, Machine Listening and Loudness

Imagine a film. It might play in a cinema with many speakers, on a television, or on headphones. Then an advertisement starts, much louder. For one program to work everywhere, the people who make programs and the companies that make equipment follow the same published rules, known as standards. This topic asks how a modern program is described, played correctly on any device at a steady loudness, and analyzed by computers.

Older mixes were made for one fixed speaker layout. Each sound went to a particular speaker, a method called channel-based audio. Modern formats can instead keep each sound separate, with data that says where it should be and how loud it is. All these sounds and their data together form the audio scene. Positions are measured from one agreed point, usually the listener. In virtual reality, the scene also changes as the listener turns or walks.

Every device must read this data in the same way. So it follows a shared model, arranged in levels. At the top is the whole program, then its parts, such as dialogue or music. At the bottom are short time sections that give each sound's position. Many broadcasts carry several versions of one show. A version the viewer can choose, such as another language, is called an audio preselection.

At home, the device receives sounds and this description, not finished speaker signals. It calculates what each speaker plays, then adjusts for where the speakers really are. For headphones, each sound is filtered differently for each ear, so it seems to come from a direction. This is called binaural rendering. Some programs instead store sound from all directions as a set of channels. The recorder and the player must agree on the order and level of those channels.

The level should also stay steady between programs. The highest peaks do not show how loud a program seems to people, so loudness is measured another way. The sound is filtered to match how the ear hears frequencies, and very quiet moments are left out. The result is one number for the whole program, called the integrated loudness. Broadcasters and streaming services set a target for it. A second reading, the true peak level, measures the highest level the sound wave reaches, which can fall between stored samples.

Computers can also analyze a program to describe what it contains. Software turns sound into small sets of numbers. From them it finds where notes begin, estimates the beat and key, or marks the chorus. Other methods separate a mixture into its sources, such as a voice and each instrument. Researchers compare these methods with shared tests.

The flashcards explain each part, with the formal names of the standards. By the end, you will know how a modern program is described and played on any system, how its loudness is measured, and how computers analyze and separate sound.
