Topic Foundations: Audio Coding and Codecs

Imagine a music album saved as raw recorded numbers. That is too much data for a busy network. So an encoder makes the data smaller, and a decoder rebuilds the sound. Together they form a codec. But how can sound lose most of its data and still sound almost the same?

The answer starts with hearing. A loud sound can hide quieter sounds near it in frequency. An encoder uses a model of hearing to find these hidden parts and spends little data on them. This method is called perceptual audio coding.

To find them, the encoder splits the sound into frequency bands, using a part called a filter bank. Each band's numbers are then rounded, which saves data but adds a little noise. Each band gets a value that sets how coarsely its numbers are rounded. That value is called a scalefactor. The encoder usually rounds more coarsely where louder sound will hide the noise. It works on short blocks of sound. A sudden drum hit can spread rounding noise across its block, even before the hit. That faint noise is called pre-echo. Shorter blocks reduce it.

At low data rates, encoders code only part of the sound fully and send short descriptions for the rest. The left and right channels are often similar. So an encoder can send one channel plus a little data about how they differ. That method is called parametric stereo. The decoder can also rebuild the high frequencies from the low ones and a little extra data. At higher rates, encoders can code what the two channels share only once.

Phone calls carry mostly speech, so they usually use a different method. Speech codecs treat the voice as two parts: a sound source, and a filter that shapes it the way the throat and mouth do. The encoder picks the source signal that sounds closest from a stored list of codes. This idea is called code-excited linear prediction. Calls need very little delay, and often fill lost data with a likely sound.

Each standard combines some of these methods and describes how the coded data must be read. This data usually comes in small blocks, each called an audio frame. Each starts with a fixed pattern that helps the decoder find it. A setup header tells the decoder the coding type, sample rate and channels.

Some standards offer lossless coding, which makes the data smaller without changing the sound. For other methods, people need to know how much the sound changed. Listeners score coded sound against the original, and computer models of hearing estimate that score.

The flashcards explain each method, the main codec families, how coded data is organized, and how quality is judged. By the end, you will know how codecs make sound data smaller, why it still sounds close to the original, and how standards keep them compatible.
