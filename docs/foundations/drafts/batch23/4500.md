Topic Foundations: Acoustic Units and Reference Values

Imagine an engineer ordering a microphone part from a factory in another country. The order gives sizes, voltages and frequencies. The factory must read every number as the engineer meant it. That works because both sides use the same units. So who defines these units, and how do they stay the same everywhere?

The agreement starts with a small set of basic units, for length, mass, time, electric current, temperature and a few more. Every other unit is built from these. This shared system is called the International System of Units. An international office keeps its definitions, and member countries vote on any change.

In audio, a microphone signal is a tiny part of a volt, and a radio signal repeats millions of times each second. So people add a short word part to the front of the unit. "Milli" makes a unit a thousand times smaller, and "kilo" makes it a thousand times larger.

Not every number uses this system. Older equipment and books still use units such as the inch or the horsepower. Some old units are only former names, such as cycles per second for the hertz. So a careful reader checks each unit.

Sound brings a special problem. The loudest sound we can hear has a huge pressure compared with the quietest one. So in acoustics, people usually state a ratio instead. It says how many times larger a value is than an agreed fixed value, called the reference. When one power is ten times another, they differ by one unit, called the bel. People usually use the decibel, one tenth of a bel.

A decibel reading must also mean the same thing everywhere. So agreed filters adjust a sound reading to roughly match how human hearing responds to different frequencies. Units are not the only shared numbers. Makers also agree on short lists of rounded numbers for common sizes and frequency bands. In such a list, each number equals the one before it multiplied by the same amount. An agreed list of this kind is called a Renard series.

These agreements are written by standards organizations at national, regional and international levels. Their rules let anyone with a real interest take part, so that no single group can control the result. A standard passes through drafts and votes, and later it may be corrected or withdrawn. The parts that state the rules are called normative, and other parts only explain. A standard often refers to another one. A dated reference names the exact year, so only that version counts. An undated reference has no year, so the newest version applies.

The flashcards explain each of these in detail, from the basic units to the way a standard is written. By the end, you will know where the units behind every audio number come from, and which parts of a standard are rules.
