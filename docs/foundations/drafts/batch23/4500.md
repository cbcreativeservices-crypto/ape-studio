Topic Foundations: Acoustic Units and Reference Values

Imagine an engineer ordering a microphone part from a factory abroad. The order gives sizes, voltages and frequencies. The factory must read every number as the engineer meant it. That works because both sides use the same units. So who defines these units, and how do they stay the same everywhere?

The agreement starts with a small set of basic units, for length, mass, time, electric current and a few more. Every other unit is built from these. This shared system is called the International System of Units. An international office keeps its definitions, and member countries vote on changes.

A microphone signal is a tiny part of a volt, and a radio signal repeats millions of times each second. So people add a short word part before the unit. "Milli" makes a unit a thousand times smaller, and "kilo" makes it a thousand times larger. Other word parts reach far smaller and far larger sizes. Each unit and word part also has a short agreed symbol. Rules also say how to write symbols, abbreviations and fractions, so a written value cannot be misread.

Older equipment and books still use units outside this system, such as the inch. Some old units are only former names, such as cycles per second for the hertz.

Sound brings a special problem. The loudest sound we can hear has a huge pressure compared with the quietest. So in acoustics, people usually state a ratio. It says how many times larger a value is than an agreed fixed value, called the reference. Each time a power becomes ten times larger, the level goes up by one step, called the bel. People usually use the decibel, one tenth of a bel.

A decibel reading must also mean the same thing everywhere. So agreed filters adjust a reading to roughly match how human hearing responds to each frequency. Frequency bands need agreed numbers too. Makers agree on short lists of rounded numbers for sizes and band frequencies. In such a list, each number is the one before it times the same amount. One such list is called a Renard series.

Standards organizations write these agreements at national, regional and international levels. Their rules let anyone with a real interest take part, so that usually no single group controls the result. A standard passes through drafts and votes, and may later be corrected or withdrawn. The parts that state the rules are called normative, and other parts only explain. When a standard refers to another, a dated reference names the exact year, so only that version counts. An undated reference has no year, so the newest version applies.

The flashcards explain each of these, from basic units and symbols to how a standard is written. By the end, you will know where the units behind audio numbers come from, and which parts of a standard are rules.
