Topic Foundations: Digital Live Sound

In the topic on analog live sound, you learned how a live system reaches the audience. In an analog system, a thick, heavy cable carries every microphone signal to the mixing console. Today many shows use a digital console instead. It looks similar, but inside it is a computer. So what changes?

The first change is that the system is often divided into parts. The part the engineer touches has faders, buttons and screens, but it does not process any sound. It only sends commands. A separate box does the mixing and effects, and a separate computer sometimes runs extra effects. The processing power of this box decides how many channels and mixes the system can handle.

Next, the sound must travel from the stage to that processing box. Microphones connect to a stage box, which changes their signals into digital data. One thin network cable then carries all the channels. That cable is called a digital snake. The microphone preamplifier is now inside the stage box, but it is still controlled from the console. Such a preamplifier is called a remote head amp. Sometimes two consoles share one stage box. When one engineer changes a shared input level, the other console automatically adjusts so its mix stays the same. That is called gain compensation.

Every step in this digital path takes a little time. Changing sound into numbers, processing it, and changing it back each add a short delay. The total delay is called latency. If it is too large, performers notice a delay in the sound they hear on stage. All parts also follow one shared timing signal, the clock, and an unsteady clock can slightly change the timing.

On the console, there are usually fewer faders than channels. So each fader controls different channels, one group at a time, and the screens show the selected channel. Many consoles add helper tools, for example to set input levels or reduce feedback. Because the processing box only follows commands, a tablet or phone can control it too. The engineer can walk around the room, and each musician can set their own stage mix.

A computer can also remember. A scene is a saved copy of all the settings, and recalling it changes many settings at once. A scene can also block chosen settings, so they stay the same when it is recalled. That is called a scene filter. Software on a laptop can show the same controls as the console, so a show can be prepared in advance. That is called offline editing.

The flashcards explain the main types of digital consoles, their processing boxes and stage boxes, timing, surface tools, scenes, control programs and effects software. By the end, you will know how a digital live system is divided into parts, how sound and commands travel through it, and what most consoles share.
