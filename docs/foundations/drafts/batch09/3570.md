Topic Foundations: Digital Live Sound

Imagine a band playing in a club. An engineer stands at a mixing console. It blends the microphone signals into the mixes the loudspeakers play. Today that console is often digital. It has the same kinds of controls as an analog console, but inside it is a computer. So what changes when the console is a computer?

First, the system is often divided into parts. The part the engineer touches has screens, buttons and faders, the sliding controls that set each channel's volume. On many systems, this part mainly sends commands, and a separate box does the mixing and effects.

Next, sound must travel from the stage to that box. Microphones plug into a stage box, a box of inputs near the performers. Inside, an amplifier makes each microphone signal stronger. The amount it adds is its gain. Because the engineer sets that gain from the console, the amplifier is called a remote head amp. The box changes the signals into digital data, and one network cable carries all the channels. That cable is called a digital snake.

Sometimes two consoles share one stage box. If one engineer changes the gain, the other console adjusts its level so its mix stays at the same loudness. That is called gain compensation.

Every step in this digital path takes a little time. Changing sound into numbers, processing it, and changing it back each add a short delay. The total delay is called latency. Performers can notice a large latency on stage. A shared timing signal, the clock, sets when each measurement of the sound is taken. If it is unsteady, the measurements come at uneven times, which can add small errors.

Because the controls often just send commands, they can change what they do. A button can switch the same faders between different groups of channels. A tablet app can send the same commands from anywhere in the room. Settings can also be saved. A scene is a saved copy of the console's settings, and recalling it changes many settings at once. A scene filter keeps chosen settings unchanged during a recall. Laptop software can show the console's screens, so a show can be prepared in advance. That is called offline editing.

That software usually works with one maker's product family. Each family has consoles of many sizes, processing boxes, stage boxes, and cards that add new connections. Some families add a separate computer that runs extra effects software, or apps that let each performer set the mix they hear on stage. Some also have assistant tools that suggest input levels or find the tones that cause feedback. The names differ, but most families share these ideas.

The flashcards explain these product families and their parts. By the end, you will know how a digital live system is divided, how sound and commands travel through it, and what most consoles share.
