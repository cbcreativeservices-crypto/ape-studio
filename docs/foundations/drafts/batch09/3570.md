Topic Foundations: Digital Live Sound

Imagine a band playing in a club. At the back, an engineer stands at a mixing console. It blends all the microphone signals into one signal for the loudspeakers. Today that console is often digital. It looks similar to an older analog console, but inside it is a computer. So what changes when the console is a computer?

The first change is that the system is often divided into parts. The part the engineer touches has screens, buttons and faders, the sliding controls that set each channel's volume. In these systems, this part mainly sends commands. A separate box does the mixing and effects. Its processing power sets how many channels the system can handle.

Next, the sound must reach that processing box from the stage. Microphones connect to a stage box, which changes their signals into digital data. One network cable then carries all the channels. That cable is called a digital snake. Inside the stage box, a small amplifier makes each weak microphone signal stronger. This preamplifier is still controlled from the console, so it is called a remote head amp. Two consoles can share one stage box. If one engineer changes a shared preamplifier, the other console adjusts its own level to keep its blend the same. That is called gain compensation.

Every step in this digital path takes a little time. Changing sound into numbers, processing it, and changing it back each add a short delay. The total delay is called latency. If it is too large, performers notice it on stage. All parts also follow one shared timing signal, the clock, and an unsteady clock can slightly change the timing.

A computer can also change what its controls do. There are usually fewer faders than channels, so the faders work in layers. When the engineer chooses another layer, the same faders control a different group of channels. Built-in helper tools can also suggest input levels or reduce feedback.

The computer can also remember. A scene is a saved copy of all the settings, and recalling it changes many settings at once. A scene can also block chosen settings, so they stay the same when it is recalled. That is called a scene filter. Laptop software can show the console's controls, so a show can be prepared in advance. That is called offline editing.

That software is usually made for one family of consoles. A family can include consoles of many sizes, extra input boxes, a separate computer that runs added effects, and apps that let performers set their own monitor mix. Each family differs in detail, but most share the ideas in this lesson.

The flashcards explain these console families and their parts in detail. By the end, you will know how a digital live system is divided into parts, how sound and commands travel through it, and what most consoles share.
