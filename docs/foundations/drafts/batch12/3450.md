Topic Foundations: Levels, Metering and Reference Standards

Imagine a small concert. On the mixing desk, rows of lights rise and fall with the music. Near the stage, a handheld device shows a number for the same song. Each number describes level, which means how large the sound or its signal is. They do not agree, but none is wrong. So what does each level number mean?

Each number is in decibels, and a decibel always compares a level with a fixed starting point. For a signal in a cable, the starting point is a chosen voltage. For sound in the air, it is a very small pressure, near the quietest sound people can hear. For digital audio, it is the highest value the system can store. Levels measured against that top value are called decibel full scale. That top value is zero, so normal digital levels are below zero.

A reference helps only if every device uses it. So engineers send a steady test sound at an agreed level through each device, until every meter shows the same number. That test sound is called a calibration tone. The agreed level is usually well below the maximum, so loud moments can go above it without reaching the maximum.

But music changes every moment, so how does a meter read it? Some meters show the highest point of the wave. Others show an average that follows the energy of the sound. The gap between the two is large for a drum hit. In digital audio, when the stored points become a continuous wave again, the wave can go higher than any stored point. So a special meter measures the true peak.

Even an average does not match hearing, because ears do not hear all frequencies as equally loud. A loudness meter changes the weight of each frequency band to follow human hearing, then averages over time. Its unit is called loudness units relative to full scale.

Sound in the air is measured with a sound level meter. A filter decides how much each frequency band counts, and a time setting decides how fast the reading reacts. For changing noise, the meter can give one steady level with the same total energy over a period. That level is called the equivalent continuous sound level. Together with time, it shows how much of a daily hearing limit a person has used.

The same methods also rate equipment. Every device adds some hiss, and some distortion, which means extra tones that were not in the input. The gap between the wanted signal and the hiss is called the signal-to-noise ratio. Every measurement also has some uncertainty, so a careful result states how much.
