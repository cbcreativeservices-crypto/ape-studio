Topic Foundations: Ableton Live

A recording program usually shows a song on a timeline that plays from start to end. But many musicians begin with short repeating parts, such as a drum pattern, and try them in different orders. Some perform with a computer on stage. So how can one program store a finished song and also be used to perform live?

It gives you two views of the same tracks. One is the timeline, called the Arrangement View. The other is a grid, called the Session View. Each column is a track, and each box can hold one short recording or set of notes, called a session clip. You start clips, or a whole row of them, in any order. Each one usually starts at the next bar (a group of beats), so everything stays in time. You record into an empty box or onto the timeline. On each track, you choose to hear the incoming sound always, never, or only while the track is set to record. In the Clip View, you then set where a clip loops and edit its notes.

Recorded sound clips stay in time together only when each one follows the song's tempo. A drum pattern recorded faster than your song usually needs to slow down without changing pitch. The program finds the beats and stretches the sound between them. Drums, a single singer and a full mixed song each usually suit a different method, called a warp mode. The program can also share that tempo with other music programs and devices.

A clip of notes makes no sound by itself. It needs an instrument. The program includes its own synthesizers and samplers, and effects such as reverb, compression and distortion. On each track, these parts form a row in the order the sound passes through them. That row is called the device chain. Several devices can be grouped into one unit, controlled by a few main knobs. One such group places a different drum sound on each pad of an on-screen grid. It is called a Drum Rack.

A hardware controller with pads and knobs can start clips and play these devices. Many controllers are set up automatically. You can also link any on-screen control to a knob or key on the controller.

You also choose where each track's sound comes from and where it goes. Most tracks are combined on one final track, and some send part of their sound to a shared effect.

The song's file is saved in a project folder and lists the sound files it uses. One command copies every sound into that folder, so no sound is missing when the project is copied to another computer.

The flashcards explain each part in detail, including each built-in instrument and effect. By the end, you will know how one set of musical ideas can be performed in any order, recorded, and finished as a song.
