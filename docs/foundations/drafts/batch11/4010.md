Topic Foundations: Ableton Live

Most recording programs show a song on a timeline. But many musicians begin with short repeating parts, such as a drum pattern, and try them in different orders. Some perform with a computer on stage. So how can one program store a finished song and also be used to perform live?

It gives you two views of the same tracks. One is the timeline, called the Arrangement View. The other is a grid, called the Session View. Each column is a track, and each box can hold one short recording or set of notes, called a session clip.

You start clips, or whole rows of them, in any order. Each usually starts at the next bar (a group of beats), so everything stays in time. A clip can also start another clip when it ends. You record into an empty box or onto the timeline. Each track can let you hear its input always, never, or only while it is set to record. A separate panel shows one clip, where you set its loop and edit its notes.

Recorded sound clips stay in time when each follows the song's tempo. A drum pattern recorded faster than your song usually needs to slow down without changing its pitch. The program finds the beats and stretches the sound between them. Drums, a single singer and a full mixed song each usually suit a different method, called a warp mode.

A clip of notes makes no sound by itself. It needs an instrument. The program includes synthesizers, which create sound, samplers, which play recordings, and effects, such as reverb. On each track, these parts form a row in the order the sound passes through them, called the device chain. Devices can also be grouped. One such group, called a Drum Rack, puts a different drum sound on each pad of a grid.

The program can also help write notes for these devices. It can keep a part you played without pressing record, move notes slightly off the beat grid, add small random changes, or keep notes in one scale. Users can also add devices, and some of these can change the program's own settings while it plays. Also, a hardware controller with pads and knobs can start clips and play these devices. Any on-screen control can be linked to a knob.

When the parts are ready, most tracks are combined on one final track, and some send part of their sound to a shared effect. The finished song is saved as a file that lists the sound files it uses, inside a project folder. One command copies every recording into it, so none is missing on another computer.

The flashcards explain each part in detail, including the built-in devices. By the end, you will know how one set of musical ideas can be performed in any order, recorded, and finished as a song.
