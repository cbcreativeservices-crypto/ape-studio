Topic Foundations: Additional DAW Platforms

Imagine that you move to a new studio, and its computer runs a recording program, or digital audio workstation (DAW), that you have never seen. You already know what such a program does. It records sound and played notes on tracks, edits them, mixes them, and saves a session. The jobs are the same, but the screens and names differ. So this topic asks: what does each program do in its own way?

The first difference is purpose. Most programs are made for writing and recording songs. Some are made for sound in films and games, or for careful editing of classical recordings. In one older kind, notes are typed into a grid that scrolls down the screen. That kind is called tracker software.

Within each purpose, programs also differ in how you set them up. You can save a layout of windows, assign several commands to one key, or add small programs of your own. You can save a ready-made track with its effects and connections, and load it into any new project. That is called a track template.

Then recording begins. A setting decides whether a new attempt is added to the old one, replaces it, or is kept separately. That setting is the record mode. Some programs keep the last seconds of sound in memory, so a part played before anyone pressed record is not lost. Attempts at the same part of the song are stacked in rows called lanes. Joining the best part from each lane into one performance is called lane comping.

Editing usually leaves the recorded files unchanged. The program stores only a list of the edits. Many programs find each sudden loud hit in a recording and mark it. A mark placed on a hit, which you can drag, is called a stretch marker. Dragging it makes the sound longer or shorter without changing its pitch, so a late note can be moved onto the beat.

Not all sound is recorded. It can also come from software instruments, which some programs show as a rack of devices joined by cables on the screen. Some cables carry only instructions, such as which note to play. Every track then reaches the mixer, where effects are added to tracks or single recordings, and levels are set. Tracks that use a lot of computer power can be changed into a fixed audio recording. Last, the mix is written to new files. A list of export jobs that the program completes one after another is called a render queue.

The flashcards explain each step, with the names that different programs use. They also cover ways to connect programs and add extensions. By the end, you will know how these programs are alike, where each one is different, and what to look for in a program you have never used.
