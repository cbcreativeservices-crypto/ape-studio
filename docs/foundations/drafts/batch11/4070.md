Topic Foundations: Synthesis Fundamentals and Oscillators

Imagine pressing a piano key. A hammer makes a string vibrate. Now imagine a keyboard with no strings. An instrument that makes sound with electronics is called a synthesizer. How can it make a sound with no vibrating object, and make it change?

A synthesizer starts with a part that produces an electrical wave that repeats its shape. That part is called an oscillator. How often the wave repeats sets the pitch. The shape sets the tone. A wave with sharp corners contains many extra high frequencies. Two oscillators tuned very slightly apart make the level of one note rise and fall slowly.

A wave with many frequencies is a useful starting point, because some can be removed. The most common filter lets low frequencies through and reduces those above a set point. That is called a low-pass filter. A resonance control raises the frequencies right at that point.

The sound now has a pitch and a tone, but it does not change over time. A plucked string, however, starts fast and fades quickly. So each key press starts a part that produces a control shape, not a sound. It sets how fast the level rises, falls to a steady level, and fades after the key is released. That part is called an envelope generator. It controls the level, and often the filter.

The envelope is one control that changes a setting during a note. Another is a slow, repeating wave that you do not hear. It moves the pitch or the filter's set point up and down. That part is called a low-frequency oscillator. Many synthesizers show which control changes which setting in one table.

Each note needs its own oscillator, filter and envelope, so the number of these sets limits how many notes play at once. In analog synthesizers, control signals travel between parts as voltages. That is called control voltage. Other signals mark when a note starts and ends. In some synthesizers, every part is a separate unit, connected by hand with cables. A device that plays a stored pattern of notes can then control all these units.

The method so far starts with many frequencies and removes some. Several other methods build sound differently. One oscillator can change the pitch of another very fast, which creates new frequencies. Tones with only one frequency can be added together. Stored wave shapes can be read in order. Computer code can calculate how a real string vibrates.

The flashcards explain wave shapes, filters, envelopes, the controls that change a sound, voltages and cables, and how many notes play at once. They also cover the main methods, gliding between notes, unwanted extra frequencies, and important instruments from history. By the end, you will know how a synthesizer produces a tone, shapes it, and changes it over time.
