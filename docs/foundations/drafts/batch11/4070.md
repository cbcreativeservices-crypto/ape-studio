Topic Foundations: Synthesis Fundamentals and Oscillators

Imagine striking a small bell. The metal vibrates, and the sound slowly fades. Now imagine an instrument with no metal, no strings and no reed, only electronic parts and a loudspeaker. An instrument that makes sound with electronics is called a synthesizer. How can it create a tone with nothing acoustic vibrating inside it, and make that tone change?

A synthesizer starts with a part that produces a wave that repeats its shape. It can be an electrical signal or a stream of numbers. That part is called an oscillator. How often the wave repeats sets the pitch. The shape sets the tone. A wave with sharp corners contains many extra high frequencies. In digital oscillators, frequencies too high to store can return as unwanted, out-of-tune tones. Two oscillators tuned very slightly apart make the level of one note rise and fall slowly.

A wave with many frequencies is a useful starting point, because some can be removed. The most common filter lets low frequencies through and reduces those above a set point. That is called a low-pass filter. A resonance control raises the frequencies right at that point.

The sound now has a pitch and a tone, but it does not change over time. A bell, however, starts loud and then slowly fades. So each key press starts a part that produces a control shape, not a sound. It sets how fast the level rises, falls to a steady level, and fades after the key is released. That part is called an envelope generator. It controls the level, and often the filter. Each held note needs its own set of these parts, which limits how many notes play at once.

The envelope is one control that changes a setting during a note. Another is a slow, repeating wave that you do not hear. It moves the pitch or the filter's set point up and down. That part is called a low-frequency oscillator.

In analog synthesizers, these controls travel between parts as voltages. That is called control voltage. A gate signal stays on while a key is held, and it tells the envelope when to start and when to fade. In a modular synthesizer, each part is a separate unit, connected by hand with cables. A sequencer can then play a stored pattern of notes, one step at a time.

The method so far removes frequencies. Other methods build sound differently. One oscillator can change the pitch of another very fast, which creates new frequencies. Tones with only one frequency can be added together. Stored wave shapes can be read in order. Computer code can calculate how a real string vibrates.

The flashcards explain these parts and methods in detail, along with gliding between notes and important instruments from history. By the end, you will know how a synthesizer produces a tone, shapes it, and changes it over time.
