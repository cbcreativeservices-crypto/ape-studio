Topic Foundations: MIDI

Imagine you press a key on a small keyboard connected to a computer. A piano sound comes from the computer's speakers. The keyboard makes no sound, and the cable carries no sound. It carries short instructions, such as which key you pressed and when you released it. So how does one device tell another what to play, when, and how?

The instructions follow a shared standard, so equipment from different makers works together. That standard is called the musical instrument digital interface (MIDI). One message says that a note starts, which note it is, and how hard you pressed the key. That value is called velocity, and a higher value usually means a louder note. Another message says that the note stops.

A note can also change while you hold it. A wheel beside the keys can raise or lower the pitch. A pedal can keep notes sounding. Knobs and pedals send changing values in a message called a continuous controller; the wheel has its own. Another message selects a different sound. Usually a change affects every note you hold, but newer methods let one note in a chord change alone.

The messages need a path between devices. Older equipment uses a round plug and a cable that carries messages in one direction. Newer equipment often uses the same cable a computer uses for a mouse, a wireless connection, or a connection inside the software. Most messages carry a channel number that selects one instrument, so one cable can control several. If a stop message is lost, the note keeps sounding until a reset message silences it. Timing is sent the same way. One device sends a steady pulse many times on every beat, and the others follow its tempo.

Because MIDI stores instructions and not sound, a recorded part is easy to change. Software usually shows each note as a bar on a grid beside a piano keyboard. A higher bar is a higher note, and a longer bar is a longer note. This view is called the piano-roll editor. You can correct a wrong note, move a late note onto the beat, or change velocities.

Many keyboards, pads and knob panels only send MIDI messages. In many programs you click an on-screen control and move a knob, and the program links them. Electronic drums also send MIDI messages. A sensor under each pad turns a hit into a signal, and the drum's control box sends a note with a velocity. Its settings stop one hit from playing twice or triggering a nearby pad.

By the end, you will know what travels between music devices, how it controls the sound, and why a performance stored as instructions is easy to change.
