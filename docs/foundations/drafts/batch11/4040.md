Topic Foundations: MIDI

Imagine you press a key on a small keyboard connected to a computer. A piano sound comes from the computer's speakers. The keyboard makes no sound, and the cable carries no sound. It carries short instructions, such as which key you pressed and when you released it. So how does one device tell another what to play, when, and how?

The instructions follow a shared standard, so equipment from different makers works together. That standard is called the musical instrument digital interface (MIDI). One message says that a note starts, which note it is, and how hard you pressed the key. That value is called velocity, and a higher value usually means a louder note. Another message says that the note stops.

A note can also change while you hold it. A wheel beside the keys can raise or lower the pitch. Knobs and pedals send changing values in a message called a continuous controller. Usually a change affects every note you hold, but newer methods let one note in a chord change alone. Another message selects a different sound. A shared list gives common sounds fixed numbers, so a song uses suitable instruments on many devices. Some instruments use special keys that make no sound and choose a playing style, such as short or long notes.

The messages need a path between devices. Older equipment uses a round plug and a cable that sends messages one way. Newer equipment often uses a standard computer cable, a wireless connection, or a connection inside the software. Most messages carry a channel number, so one cable can control several instruments. For timing, one device sends a steady pulse many times on every beat, and the others follow its tempo.

Because MIDI stores instructions and not sound, a recorded part is easy to change. Software usually shows each note as a bar on a grid beside a piano keyboard. A bar placed higher on the grid is a higher note, and a longer bar is a longer note. This view is called the piano-roll editor. You can correct a wrong note or move a late note onto the beat. A whole performance can be saved in a shared song file for other programs.

Many keyboards, pads and knob panels make no sound and only send these instructions. In many programs you click an on-screen control and move a knob, and the program links them. Electronic drums also send MIDI messages. A sensor under each pad turns a hit into a signal, and the drum's control box sends a note with a velocity. Its settings stop one hit from playing twice or triggering a nearby pad.

The flashcards explain each kind of message, connection and device in detail. By the end, you will know what travels between music devices, how it controls the sound, and why a stored part is easy to change.
