Topic Foundations: Console Architecture and Bus Structure

Imagine a band in a small club. Every microphone connects to one mixing console. Each signal arrives on its own channel, a column of controls. The audience needs one blend of all the sounds. The singer needs a different blend in the speaker at her feet. So how is one console organized to make many mixes from the same inputs at once?

The answer is a set of shared paths inside the console. Each path adds many channels together into one signal. The main path, to the left and right outputs, is called the mix bus. A knob on each channel sends a copy of its signal to another path, at its own level. That knob is called an aux send, short for auxiliary send. One send for each performer gives each one a personal mix. Other outputs, called matrix outputs, mix the main outputs again for other areas, such as a lobby.

Channels are often grouped. The drum channels can share one path with one fader, a sliding level control. That is called a subgroup, because the drums are added into one signal. A second kind of group does not add the sound together. Its fader only changes the level of each assigned channel. On digital consoles, this kind of group is called a digitally controlled amplifier, because the fader only sends a level number to each channel. A mute group silences several channels with one button.

Each channel also needs a position between the left and right speakers. A knob sends more of the signal to one speaker than to the other. That knob is called a pan pot. A centered sound plays from both speakers and can seem louder, so many consoles turn it down a little.

With so many mixes, the engineer needs to hear each one. One section sets the level of the control-room speakers and can switch to a second pair. A button on each channel sends that channel alone to the engineer. That is called solo. Usually solo changes only what the engineer hears. But some solo modes mute all other channels in the main output. During a show, the audience would hear only one channel, so engineers check the mode first.

Consoles can be built in two ways. On an analog console, the sound usually passes through the knobs and faders themselves. On many digital consoles, the controls only send commands to a separate processing unit. So the same faders can show a different set of channels when a button is pressed. Because every setting is a number, all settings can be saved and reloaded. A protected channel keeps its settings when they load.

The flashcards explain the paths, groups, monitoring controls and ways consoles are built. By the end, you will know how a console makes many mixes from the same inputs, and how they are checked and saved.
