Topic Foundations: Console Architecture and Bus Structure

Imagine a band in a small club. Every microphone connects to one mixing console. Each signal arrives on its own channel, a column of controls. The audience needs one blend of all the sounds. The singer needs a different blend in the speaker at her feet. So how is one console organized to make many mixes from the same inputs at once?

The answer is a set of shared paths inside the console. Each path adds many channels into one signal. The main path, to the left and right outputs, is called the mix bus. Each channel can also send a copy of its signal to another path, with its own knob for the level. That extra output is called an aux send, short for auxiliary send. One send per performer gives each a personal mix. Other outputs, called matrix outputs, mix the main outputs again for other areas, such as a lobby.

Channels are often grouped. The drum channels can share one path with one fader, a sliding level control. That is called a subgroup, because the drums are added into one signal. A second kind of group does not add the sound together. Its fader only changes the level of each assigned channel. On digital consoles, this group is called a digitally controlled amplifier, because its fader only sends a level number.

The main mix is in stereo, so each channel also needs a position between the left and right speakers. A knob called a pan pot sends more of the signal to one speaker than to the other. A centered sound can seem louder, so many consoles turn it down a little.

With so many mixes, the engineer needs to hear each one. One section sets the level of the control-room speakers. A solo button on each channel sends that channel alone to the engineer. Usually solo changes only what the engineer hears. But some solo modes mute all other channels in the main output. During a show, the audience would hear only one channel, so engineers check the mode first. A talkback button lets the engineer speak to the performers.

Consoles can be built in two ways. On an analog console, the sound usually passes through the knobs and faders themselves. On many digital consoles, the controls only send commands to a separate processing unit. So the same faders can control a different set of channels when a button is pressed. Because every setting is a number, a complete set can be saved and loaded later. A saved set is called a scene. A protected channel keeps its current settings when a scene loads.

The flashcards explain the paths, groups, monitoring and talkback controls, scenes, and ways consoles are built. By the end, you will know how a console makes many mixes from the same inputs, and how they are checked and saved.
