Topic Foundations: Archival Preservation & Obsolete Media

Imagine a library storeroom full of old recordings. There are hollow tubes with a groove, heavy discs, and thin plastic belts from an old office. Almost nobody owns a machine that can play them now. How is their sound saved before they fail? And once it is a computer file, how does an archive keep that file correct and unchanged for many years?

Each of these objects carries sound, and caring for the object itself is called carrier preservation. Radio stations and families once recorded on soft discs that could be played back at once. Such a disc is called an instantaneous disc, and it is often the only copy. Every one of these objects ages. Such a disc's soft coating can shrink until it cracks and separates from its hard center. The tube-shaped records, called cylinders, can grow mold or change shape. So staff record each item's condition, and the items most likely to fail are copied first.

Copying starts with careful playback. Staff identify the format and its speed, because the wrong machine can damage a fragile original. Cylinders too fragile for any needle can be photographed instead, and a computer turns the groove image into sound. The copy keeps everything on the original, including hiss and clicks. This rule is called archival neutrality.

The finished copy is a computer file, and files can also be damaged without warning. So the computer calculates a short code from each file's exact data and saves it. If the code still matches later, the file has stayed exactly the same. This proof is called fixity. Archives also keep several copies in buildings far apart and on different kinds of storage. That is called replication.

Storage equipment and file types also go out of use, so newer computers may not read them. So archives copy their files onto newer storage before the old storage stops working. When a file type is at risk, the content is copied into a newer type that current programs can open. That is called format migration.

A sound file alone does not tell you what it contains. An archive also records what each recording is, where it came from, and what was done to it. Many archives follow one shared model for receiving material, storing it, and providing it to users. The bundle of sound and its written description kept for the long term is called an archival information package. Listeners receive a smaller copy, so the kept version stays untouched.

The flashcards explain the old objects and how they decay, how their sound is copied, and how archives check, copy, move and describe files. By the end, you will know how sound is saved from objects that almost nobody can play, and how its files stay correct and unchanged.
