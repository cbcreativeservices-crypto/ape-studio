Topic Foundations: Archival Preservation and Obsolete Media

Imagine a museum room full of old machines for playing sound. One plays tubes with a groove, one plays heavy discs, and one plays thin plastic belts. The machines are rare now, and few people can repair them. But many recordings made for them still exist. So how is their sound saved before the recordings fail, and how is the saved file kept correct for many years?

Each tube, disc and belt carries sound, and caring for the object itself is called carrier preservation. Radio stations and families once recorded on soft discs that could be played back at once. These are called instantaneous discs, and each one is often the only copy. Their coating can shrink until it cracks and separates from the hard center. The tube-shaped records, called cylinders, can grow mold or change shape. The items most likely to fail are copied first.

Copying starts with careful playback. Staff identify the format and its speed, because the wrong machine can damage a fragile original. Cylinders too fragile for any needle can be photographed instead, and a computer turns the groove image into sound. The copy keeps everything on the original, including hiss and clicks. This rule is called archival neutrality.

The finished copy is a computer file, which can also be damaged without warning. So the computer calculates a short code from the exact data of each file and saves it. Later, the code is calculated again and compared. This test is called a fixity check. If the codes match, the file has stayed exactly the same. A whole drive can still fail, so archives keep several copies in buildings far apart. That is called replication. The copies are also kept on different kinds of storage, so one fault cannot damage every copy.

Storage equipment and file types also go out of use. Archives copy their files onto newer storage before the old storage stops working. When a file type is at risk, the content is copied into a newer type that current programs can open. That is called format migration. This work is planned years ahead, so risks are found early.

A sound file alone does not tell you what it contains. An archive also keeps written information about each recording. It describes what the recording is, how the file was made, where it came from, and every step taken to keep it safe. The sound and this information, stored together for the long term, are called an archival information package.

The flashcards explain each part in detail: the old objects and how they decay, how their sound is copied, and how archives check, copy, move and describe their files. By the end, you will know how sound is saved from objects that almost nobody can play, and how its files stay correct and unchanged.
