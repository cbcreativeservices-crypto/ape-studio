Topic Foundations: Audio Signal Processing, Music Analysis and Ethics

Imagine you sing into a music program and add an echo. The computer stores the sound as numbers and changes them. That work is called digital signal processing. Other software studies music, and some can copy a voice. So how does audio software finish its work in time, how does it find facts in music, and how can people check where a sound came from?

The first problem is time. The program receives sound values in small groups. It must return each changed group before the equipment needs it. That moment is called the real-time deadline. If the program is late, you often hear a click. So the audio code should not wait for slower work, such as loading a file.

To meet the deadline, digital mixing consoles often use small chips built for fast signal math. Many of these chips store only a narrow range of numbers. A value that grows too large is usually held at the highest value. Otherwise it jumps to a wrong value and makes loud noise. Engineers also use faster methods for long reverbs. The sample rate is the number of sound values each second. Some effects use a higher sample rate inside, to avoid unwanted tones.

Many of these calculations are filters, which make some frequencies louder or quieter. Some filters change their own settings. On a call, the other person's voice can return from your speaker into your microphone as an echo. A filter compares the echo it expects with what the microphone hears, and corrects itself. That is called an adaptive filter.

Other software only studies sound. It finds the start of each note, the beat, the chords, the key and the tempo, which is the speed of the music. It can also sort music by style and suggest songs a listener may like. This field is called music information retrieval. A short summary of a recording's sound can identify a song.

Software that learns from recordings can also copy a person's voice. So the last question is whether a voice or a file is real. One protection is a hidden signal that people cannot hear but software can read. That is called audio watermarking. Other software can often detect whether a voice is computer-made. A protected record stored with the file can show where it came from and how it was changed. Copying a voice should begin with permission, which is called voice cloning consent. In many places, the law also protects a person's voice. Recordings used to train these systems raise the same questions of permission and privacy.
