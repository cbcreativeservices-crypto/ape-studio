## Rule book notes

1. **C13: name the look-alike families.** Add: "¼-inch TRS and TT/bantam patch plugs are different families; neither fits the other's jack." Also consider: "Long-frame (B-gauge) ¼-inch patch plugs and standard (A-gauge) TRS plugs have different tip profiles; a standard plug can spread a B-gauge jack's springs (verify)." This rule would have caught B-PB-01.
2. **Missing rule: never passively join two outputs.** Proposed wording: "Two outputs are never tied together into one input (Y-cable, two-feed patch); one output may feed several high-impedance inputs." Status U. Connector Select teaches it; the Patchbay lab breaks it (PB-01). Needs its own ID (for example F9).
3. **Missing rule: cable classes in bundles and supports.** Proposed wording: "Mic/line, loudspeaker, mains and data run as separate groups, in separate bundles and on separate supports where practical; where groups must meet, they cross at 90° (R2)." Status C. The Rack scene already follows this, and it would have caught B-CI-03.
4. **C7 status is too strong.** "2+/2− carry … high band in bi-amp" is marked U, but the Cable lab's own records say "often LF/HF — verify" and equipment-dependent (`connectors.speaker.ts:202-214`). The full-range 1± part is U; the bi-amp band assignment should be **C**.
5. **C9: add AES3id.** Proposed wording: "AES3id: 75 Ω unbalanced on BNC." Connector Select teaches it (`jobs.ts:98`), but no rule covers it.
6. **L3: add the wedge case.** Proposed wording: "A snake return or a console mix output is line level: it feeds a powered wedge or an amplifier, never a passive wedge directly." This would have caught B-CI-01.
7. **Missing patchbay rule: half-normal break side varies.** Proposed wording: "Which side of a half-normal pair breaks varies by bay (top-breaking bays exist): verify the bay." Status C. The lab already teaches it (pagesD); the rule book should hold it so other labs follow it.
8. **XLR/TRS combo geometry.** Proposed wording: "¼-inch in the centre, XLR contacts around it; phantom on the XLR pins only." Status C for the phantom part. This would have caught B-CB-01.
9. **R1 cites "D69".** Register MK-05 says governance numbers the lane rule D70. Align the rule book's cite.
