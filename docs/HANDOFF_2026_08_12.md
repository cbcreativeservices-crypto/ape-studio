### Listening Exposure Monitor (dosimeter) — key facts
- `src/features/audio/exposureMonitor.ts` — centralized service, ONE combined
  timeline. Tracks BOTH **output** (playback, estimated from source dBFS + an
  adjustable reference) AND **incoming** (mic-measured environmental level while
  a measurement tool runs — measured when field-calibrated, else estimated).
  Max per tick, never summed. 3 dB-exchange dose (OSHA/conservative selectable),
  persists, midnight reset, 45-day history. Poller arms only while foregrounded
  AND (output can sound OR mic capturing) — no background cost.
- **Runs SILENTLY in the background.** Interaction is ONLY via the **ToolsHub
  dosimeter chip** (live readout + OPEN → `ExposureMonitor` modal) and the
  **15-minute check-in** overlay (`ExposureCheckin.tsx`, red line becomes the
  panel's bottom edge; routine/advisory check-ins ONLY inside audio tools/labs;
  critical dose warnings anywhere). No per-tool controls.
- `ExposureMonitorScreen.tsx` (route `ExposureMonitor`, modal, ungated) — session
  / today / by-source / 7–30 day history / settings / calibration / privacy.
