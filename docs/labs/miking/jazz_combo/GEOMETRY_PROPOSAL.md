# E15 Jazz Combo: GEOMETRY PROPOSAL

Stage-plot preset (E09 tooling) with combo tokens: drum kit (jazz, closed-front kick), upright bass, grand piano
(lid direction switch), guitar combo, sax/trumpet soloist, singer. Positions drawing defaults.
Architectures as saved plots: `shared` (one array, §A), `shared+spots`, `close`, `hybrid` (close mics to PA, room
pair to record/stream only). Readouts: spill matrix (free field), amp-axis arrows (Xepoleas "faced the guitar amp
away from the drums" as the demo move), NOM penalty, routing-role matrix; Glyn Johns links to `overheads/`.
Keep-outs: piano lid sweep, bass endpin, horn bell axis.
