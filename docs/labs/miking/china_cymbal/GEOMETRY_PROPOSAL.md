# I01e China Cymbal: GEOMETRY PROPOSAL

Frame K, classes: `hihat/GEOMETRY_PROPOSAL.md`. New family member **`CHINA_18`**: Ø 457.2
(SOURCED). New profile (all DRAWING DEFAULT, "drawing default, not a published figure"):

| Profile part (radius fraction of R = 228.6) | Default | Note |
|---|---|---|
| cup (cylindrical, flat top) | r 0–0.18 R (0–41.1), 25 high | China cups are squarer than a crash bell (no source gives a number) |
| shoulder / bow | r 0.18–0.78 R, falls to the valley | |
| valley (lowest ring) | r 0.78 R = 178.3 | strike point: "about an inch above" the valley on the shoulder → r ≈ 0.78 R − 25.4·cos(10°) ≈ 153.3 (DERIVED from SAB-JH under the 10° shoulder slope default) |
| upturned lip | r 0.78–1.0 R, rises 18 above the valley at 25° | |
| rivets (option) | 6 equally spaced, r = R − 38.1 = 190.5 | TRIAL (ZIL-FAQ pattern) |

Mount variants: `upright` (cup up; Hamilton jazz ride) and `inverted` (cup down, lip pointing
up toward the stick — "crash it"). Default kit position: the crash2 stand (250, h 1200, 360)
replaced by the China, or a new stand beside the ride (drawing default (150, h 1150, 700)).
