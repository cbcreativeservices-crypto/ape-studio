# I01d Splash Cymbal: GEOMETRY PROPOSAL

Frame K, classes: `hihat/GEOMETRY_PROPOSAL.md`. New family member: **`SPLASH_10`** (Ø 254.0,
SOURCED ZIL-ASPL/KSPL) and `SPLASH_8` (Ø 203.2) with the family profile (drawing defaults:
8 % rise, 20 % bell). Three mount variants (lesson L"standalone / piggyback / stack"):

| Variant | Geometry | Class | Source |
|---|---|---|---|
| `mount.arm` | splash on an MC-CY2-type Z-rod (Ø 9.525) clamped to the crash1 stand tube, between tom1 and crash1; centre drawing default (−150, h 1000, −380), tilt 10° | rod Ø SOURCED; position/Z offsets DRAWING DEFAULT | MEINL-CY2 |
| `mount.piggyback` | 8 in splash INVERTED on top of crash2 (or the 20 in ride), sharing the tilter rod; splash edge plane 25 above the host bell top, felt between | SOURCED arrangement (ZIL-BARATA); spacing DRAWING DEFAULT | ZIL-BARATA |
| `mount.stack` | FX-Stack-type three plates (two larger + one smaller) on one bolt, "tight" (plates touching) or "loose" (5 mm gaps) | arrangement SOURCED (ZIL-FXS); gaps DRAWING DEFAULT | ZIL-FXS |

| Zone | Region | Class |
|---|---|---|
| `zone.splash.overhead` | the M09 pair ("do the overheads carry the cue?") | lesson |
| `zone.splash.top` | above the splash, aimed at the bow, 150–250 above, outside the swing and the stick | DRAWING DEFAULT (lesson: "an engineering starting suggestion", no number) |
| `zone.splash.under` | under the splash (arm mount only), 80–150 below, aimed up | DRAWING DEFAULT |

| Keep-out | Region | Class |
|---|---|---|
| `ko.swing` | ±60 at the edge (family); piggyback/stack: the host cymbal's swing as well, and the host's motion carries the splash | DRAWING DEFAULT |
| `ko.lowerPlate` | stack/piggyback: the lower plate's swing band (lesson "lower cymbal's movement") | DRAWING DEFAULT |
| `ko.stick`, `ko.choke` | as crash | ILLUSTRATIVE |

Owner: arm position, piggyback spacing and stack gaps are drawing defaults; no source gives a mic
distance. The stack is the hardest art in I01 (survey) — build `mount.arm` first.
