# G1 · Foundations of Sound (FoundationsCourse) — beginner audit

Auditor G1, 2026-11-14, web preview `http://localhost:8142/#labpreview/FoundationsCourse` at 390 x 844, sound OFF (PLAY never pressed; Sound Safety never accepted).
14 modules in one stepped screen (MODULE n / 14). Every module = Rack display on top, readout strip, text well, CHECK YOURSELF, dock keys at the bottom. Each module opens its own intro card (WHAT YOU'RE LEARNING / WHERE TO START). The lab's first open also shows a "Sound" word card.

Shared frame notes that apply to every module (written once here, referred to as F1–F6 below):
- **F1. The text well is a letterbox.** With the display shown, only about 6 lines of lesson text are visible between the display and the dock. A beginner reads through a slot and scrolls a lot; the CHECK YOURSELF and the green NEXT button are always below the fold. (SHARED: rack layout)
- **F2. Same value shown three times.** e.g. Module 3: slider tray "STRENGTH strong · 100 %", dock key "STRENGTH · 100%", readouts "STRENGTH strong" + "LEVEL 100%". Three places to look for one number. (SHARED: DockTray + readout strip)
- **F3. Fourteen intro cards.** Every module opens a card before the learner can see the display. The cards are good (a goal and a first step per module, exactly what a beginner needs), but by module 4 the reflex is to tap GOT IT without reading. Module 7 shows TWO cards (before and after the prediction). (SHARED: intro card)
- **F4. Instructions that need sound.** Several WHERE TO START lines end with "then tap PLAY…". Sound-off, the learner can still do everything else on every module I saw.
- **F5. CONCEPTUAL MODEL — SLOWED FOR VISIBILITY** caption appears twice per module (under the display and in the text). Good honesty, but it is noise by module 3.
- **F6. Readouts can be long-pressed "for its lesson"** (screen-reader label) but nothing on screen tells a sighted user that. The ⓘ at the end of the readout strip opens a short "what this does" sheet; it speaks of "the gray dots in the AIR window" while the dots are white and the window is not labelled AIR in Module 1.

## Lab verdict — Foundations of Sound

**Beginner's journey.** The first six modules are a genuinely good beginner course: one picture, one idea, one slider, an intro card that names the goal and the first move, and a check question whose hint sends you back to the picture. The learner leaves Module 6 knowing air rocks in place, amplitude is size, frequency is rate and bass is long. Module 7 is the cliff: a lovely predict-the-answer moment (with the answer printed underneath it) turns into a two-ruler, fifteen-label display. From there the course climbs fast (octaves, dB curves, phase, harmonics, Fourier) and each module adds new symbols (8ve, dB, F0, λ, °) on a phone where only about six lines of text show at a time. Sound-off, every module still demonstrates its point visually, which is a real strength. The 13-line recap at the end is excellent.

**3 biggest orientation problems**
1. Module 7's after-state is far too dense for a beginner (two opposite-running rulers, many tiny labels, the steps hidden in the text) and THE GOAL box gives away the prediction's answer.
2. Symbols and units arrive unexplained and stay that way: MODEL (Module 1), Hz before Module 5, 8ve, dB/dBFS (used heavily in 9 and tested in 13, never defined plainly), F0/SEL, λ/FITS as bare readouts.
3. Developer messages shown to learners in Modules 10 and 11 ("This engine build predates… install the newest dev build…"), plus an intro card that asks for a PLAY key the module does not have (11).

**3 best things**
1. One-idea-per-module structure with a per-module intro card (goal + first step) and a well-built CHECK YOURSELF whose wrong-answer hints point back to the picture.
2. Pictures that teach without sound: tracer dots that stay home, the human figure for wavelength scale, SEND vs HEARD, the flat line at 180°.
3. The end: "YOU BUILT THE WHOLE MODEL" 13-line recap plus three cumulative checks.

**First 30 seconds rewrite.** One card: "14 short modules. Each shows ONE idea about sound with a moving picture and one control. About 2 minutes each. Start: watch the pink dots — they never leave home." Module 1 opens with only the air picture and PITCH (shown as LOW / MID / HIGH, no Hz yet), no MODEL/TONE readouts, and the check question visible without scrolling. Introduce Hz in Module 5, dB in its own short box before Module 9, and split Module 7 into "the recording view" then "the room view".
